The mental model: one line per tab

If you remember only one page, remember this one. Every debugging session starts by picking the right tab for the question you're asking.

ElementsWhat is on the page right now (the live DOM and its CSS).
ConsoleRead the page's messages and run JavaScript inside the page.
SourcesPause the code and step through it line by line.
NetworkWhat the page asked the server for, and what it got back.
PerformanceWhat the browser was busy doing, millisecond by millisecond.
MemoryWhat the page is holding on to, and why it isn't freed.
ApplicationWhat the site stored on your machine: cookies, storage, caches, service workers.
SecurityWhether the connection and its certificate can be trusted.
LighthouseAn automated report card: performance, accessibility, best practices, SEO.
RecorderRecord user steps, replay them, and export them as tests.

The first skill to learn and teach: open the request in Network and look at its Response. If the data is wrong, the bug is in the backend. If the data is right but the screen shows it wrong, the bug is in the frontend.
