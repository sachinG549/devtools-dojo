Performance

Lab 04 · The sluggish filter

Mission: Typing in the filter box feels frozen. Measure how bad it is (INP), find the function responsible, and explain what it does wrong.

Showing 0 people

    Hint 1Open Performance and type in the box. Watch the INP card under Live metrics. Set CPU throttling to 4× to make the problem clearer.
    Hint 2Record a trace while typing a few letters. Find the long task (red triangle) and open Bottom-Up, sorted by Self time.
    Solution

    On every keystroke, slowNormalize() rebuilds a huge string for each of the 2,000 names. That turns each keystroke into a long task of hundreds of milliseconds, which pushes INP into the red.

    Fix: normalise each name once when the list loads, debounce the input, and do only cheap work in the handler. Bottom-Up shows slowNormalize at the top by Self time, and its source link takes you to the line.
