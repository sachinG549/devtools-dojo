Mission: A customer says their order total is wrong: it shows $0.30 but they paid much more. Decide whether this is a backend bug or a frontend bug, and prove it.

Order …

Total: …

Hint 1Open Network → Fetch/XHR and click Reload order. Find the order.json request.
Hint 2Compare the Preview tab with what the page shows. Then check the Initiator to find the code that renders it.
Solution

The response has "total_cents": 3000 and "currency": "USD". That's $30.00, so the backend is correct.

The frontend divides by 10,000 instead of 100 (formatMoney()), so it shows $0.30. It's a frontend bug. Click the Initiator link to jump to the fetch, or search all sources (Cmd + Option + F) for 10000.

This is Playbook A from the guide: right data in the Response and wrong data on screen means a frontend bug.
