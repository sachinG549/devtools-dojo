Lab 02 · Nothing happens, no error

Mission: Clicking "Calculate total" should show the cart total. Nothing happens and the Console is empty. Find the exact line that fails and the value that causes it.

Total: –

Hint 1An empty Console doesn't mean there was no error. Something might be catching it and staying quiet.
Hint 2Sources → right pane → Breakpoints → tick Pause on caught exceptions, then click the button again.
Solution

The debugger pauses inside priceOf() on item.price.amount. In the Scope pane, item is the third cart entry, { name: 'Gift card' }, which has no price field. The resulting TypeError is caught by an empty catch {} block, so nothing gets logged.

Lessons: empty catch blocks hide bugs. "Pause on caught exceptions" finds them, and the Call Stack shows how execution got there.
