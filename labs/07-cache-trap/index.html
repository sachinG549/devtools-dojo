Lab 07 · "I deployed, but users still see the old version"

Mission: Version 2.0.0 was "deployed": the Simulate deploy button below makes the server return 2.0.0. The page keeps showing 1.0.0, even after a hard reload. Find out who is serving the old file, and get the new version to show.

Running version: …

Hint 1Network → click version.json. What does the Size column say? Does ticking "Disable cache" help?
Hint 2Application → Service workers and Cache storage.
Solution

A service worker answers version.json from Cache storage (lab07-v1) and never goes to the network. Network shows (ServiceWorker) in Size. "Disable cache" and hard reload only bypass the HTTP cache, not a service worker's cache.

Fix it in DevTools: Application → Service workers → tick Bypass for network (or Unregister), or Cache storage → delete lab07-v1. Then reload. In real code, use a network-first strategy for version files, or version the cache name on each deploy.
