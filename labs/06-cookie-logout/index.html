Lab 06 · Logged out after one minute

Mission: After "logging in", users get logged out about a minute later, and also when they open a second page of the site. Find both causes using the Application panel only.

Hint 1Application → Storage → Cookies → this origin. Look at the Expires / Max-Age and Path columns for lab_session.
Hint 2Also look at Session storage and Local storage. Which one does the app check, and which one survives a new tab?
Solution

Cause 1: the cookie is set with max-age=60, so it expires after 60 seconds. The Expires column shows a time one minute in the future.

Cause 2: the cookie's Path is limited to this lab's folder (/…/06-cookie-logout/), so other pages of the site never receive it. The app also stores its user profile in Session storage, which is per tab, so a new tab starts empty.

Practise: edit the cookie's Expires value by double-clicking it, delete the cookie to simulate an expired session, and run document.cookie in the Console to see what JavaScript can read.
