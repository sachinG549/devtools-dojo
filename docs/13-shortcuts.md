# 13. Shortcuts cheat sheet

| Where | Shortcut | Action |
|---|---|---|
| Global | `Cmd + Option + I` | Toggle DevTools |
| Global | `Cmd + Shift + C` | Element picker |
| Global | `Cmd + Shift + P` | Command menu |
| Global | `Cmd + P` | Open file |
| Global | `Cmd + Option + F` | Search all sources |
| Global | `Esc` | Toggle drawer |
| Global | `Cmd + Shift + M` | Device toolbar |
| Global | `Cmd + [` / `Cmd + ]` | Previous / next panel |
| Global | `Cmd + Shift + D` | Toggle last dock position |
| Global | `Cmd + R` / `Cmd + Shift + R` | Reload / hard reload |
| Global | Long-press reload button (DevTools open) | **Empty cache and hard reload** |
| Elements | `H` | Hide element |
| Elements | `Option + click` arrow | Expand all children |
| Elements | `Cmd + F` | Search DOM (text / selector / XPath) |
| Elements | `Cmd + Z` | Undo edit |
| Console | `Cmd + K` | Clear |
| Console | `Shift + Enter` | New line |
| Sources | `F8` / `F10` / `F11` / `Shift + F11` | Resume / over / into / out |
| Sources | `Cmd + B` | Toggle breakpoint on current line |
| Sources | `Cmd + Shift + O` | Go to function |
| Sources | `Ctrl + G` | Go to line |
| Performance | `Cmd + E` / `Cmd + Shift + E` | Record / record and reload |
| Performance | `W A S D` | Zoom and pan the trace |
